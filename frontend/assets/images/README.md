# Images

The four pictures used by the site (logo + three hero illustrations) are currently
loaded from their original online URLs inside `frontend/index.html`.

To make the project fully offline, download them into this folder and update the
`src` attributes in `index.html`:

| File name         | Used for              |
|-------------------|-----------------------|
| `logo.png`        | CampusFind logo       |
| `signin-hero.jpg` | Sign-in banner        |
| `signup-hero.jpg` | Sign-up banner        |
| `campus-hero.jpg` | Home page hero image  |
